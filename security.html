Security Disclosure

Report security issues privately.

Orbit Chat handles private messaging data. Please do not open public issues for suspected vulnerabilities involving authentication, encryption, private keys, update signing, media access, or backend authorization.

Report desktop issue Report server issue Back to Orbit Chat

What to include

Send enough detail for maintainers to reproduce and assess impact without exposing real private data.

Useful details

Include the affected app or server version, operating system, endpoint or workflow, reproduction steps, expected behavior, actual behavior, and whether plaintext, private keys, tokens, recovery codes, or update signing could be affected.

Do not send secrets

Do not include real private keys, conversation keys, recovery codes, access tokens, refresh tokens, signing certificates, or private message content in a report.

Response target

The project aims to acknowledge credible reports within 7 days, confirm impact when reproducible, and publish a security note after users have had a reasonable update window.

Production trust status

Orbit Chat is preparing for signed releases, reliable updater metadata, CI checks, backup recovery procedures, and third-party review.

Audit status
Orbit Chat should not be described as externally audited until a third-party security review has been completed and published.
